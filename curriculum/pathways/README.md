# Learning Pathways

The repository supports more than one way to study.

## Pathway Styles

- `role-first`: stay inside one track from L01 to L10.
- `foundation-first`: finish L01-L03 across all tracks before specializing.
- `mission-first`: start from a project that interests you, then backfill the levels required to understand it.
- `capstone-first`: inspect an advanced project, map your gaps, and descend into earlier levels intentionally.

## Why Shared Missions Matter

A single project can teach different lenses:

- analytics: define metrics and communicate findings;
- data science: model the signal and quantify uncertainty;
- data engineering: build reliable data flow and contracts;
- ML engineering: package and monitor the model system;
- scientific computing: derive or simulate the underlying process.

This avoids duplicating projects into artificial track silos.
