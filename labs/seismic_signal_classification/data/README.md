# Data notes

This project writes generated artifacts under `data/processed/`:

- `curated_portfolio_waveforms.npz`
- `curated_portfolio_metadata.csv`
- `dataset_provenance.csv`
- `reports/`
- `models/`

The dataset is a deterministic, local portfolio subset that approximates a
three-class seismic taxonomy inspired by public references documented in
`dataset_provenance.csv`.
