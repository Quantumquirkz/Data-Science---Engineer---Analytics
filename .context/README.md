# Repository Context Index

This folder contains the structured context for the GitHub repository
`Quantumquirkz/data-intelligence-engineering`.

Author: **Jhuomar Boskoll Quintero**

The purpose of this repository is to serve as a practical workspace for Data
Science, Data Engineering, Data Analytics, and ML Engineering projects,
workflows, tools, experiments, and end-to-end solutions built for learning and
real-world impact.

## Context Documents

- [Repository Overview](repository-overview.md) - mission, scope, audience,
  repository identity, and the main operating model.
- [Architecture](architecture.md) - filesystem architecture, project template,
  execution flow, and dependency model.
- [Project Taxonomy](project-taxonomy.md) - portfolio domains, project families,
  and how the 100-project catalog is organized.
- [Engineering Conventions](engineering-conventions.md) - development,
  reproducibility, data, modeling, and documentation conventions.
- [Agent Operating System](agent-operating-system.md) - local agents, rules,
  and skills adapted from the `garrytan/gstack` workflow pattern.
- [Metadata](metadata.json) - machine-readable repository metadata.

## How To Use This Context

Use this directory as the canonical orientation layer before modifying the
repository. It is intended for:

- Human contributors who need to understand the repository's intent and layout.
- AI coding agents that need stable grounding before editing files.
- Future documentation work, portfolio generation, and project catalog updates.
- Technical reviewers evaluating reproducibility, maintainability, and
  scientific rigor.

The context should be updated when the repository changes in a structural way:
new project families, dependency strategy changes, renamed directories, new
deployment patterns, or major changes in author/repository identity.
