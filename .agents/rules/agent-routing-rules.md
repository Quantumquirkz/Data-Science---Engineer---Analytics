# Agent Routing Rules

Use the smallest capable role or skill for the task.

## Role Routing

- Strategy and scope: Data Product Strategist.
- Pipelines and module boundaries: Data Platform Architect.
- Statistical and ML validity: ML Research Scientist.
- README, charts, portfolio narrative: Analytics Storyteller.
- Runtime validation: QA Reproducibility Auditor.
- Secrets, privacy, and governance: Security Data Governance Officer.

## Skill Routing

- New project spec: `data-project-spec`.
- Pipeline architecture review: `data-pipeline-architecture-review`.
- ML experiment review: `ml-experiment-review`.
- Data/reproducibility audit: `data-quality-reproducibility-audit`.
- Documentation generation: `portfolio-documentation-generate`.
- Security/data governance audit: `security-data-governance-audit`.
- Project QA smoke test: `project-qa-smoke-test`.

## Escalation

Use multiple roles when:

- A modeling change also affects data privacy.
- A new project needs both scope and architecture.
- A notebook result needs scientific validation and documentation.
- A dependency change affects reproducibility and security.
